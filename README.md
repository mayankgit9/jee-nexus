# JEE NEXUS

**A premium, free JEE Main previous-year-question practice and CBT (computer based test) platform.**

> Status: **active development** — built in the open. See [`DEVELOPMENT_LOG.md`](./DEVELOPMENT_LOG.md) for real progress.

Live site: **https://jee-nexus-5wd.pages.dev**

## What this is

JEE NEXUS exists to give JEE Main aspirants the most faithful free practice experience possible:

- **Authentic PYQs** — previous year questions (2019–2026 target) with original exam metadata: year, date, shift, question number and source attribution. Never fabricated.
- **Authentic diagrams** — physics circuits, graphs, geometry figures and chemistry structures, clearly attributed; originals never replaced by AI approximations.
- **Extremely detailed solutions** — concept recap, required formulas, full step-by-step derivation with substitutions, alternative methods, common mistakes and final verification — not just an answer key.
- **A real CBT experience** — NTA-style question palette, mark for review, save & next, subject sections and a server-authoritative timer with auto-submission.
- **Honest analytics** — accuracy, chapter strengths, time trends and mock history. No fake percentile predictions.

## Architecture

| Layer | Technology |
| --- | --- |
| Frontend | Next.js (App Router) + React + TypeScript + Tailwind CSS + shadcn/ui + Framer Motion |
| Math & chemistry notation | KaTeX (+ mhchem for chemical equations) |
| API | Next.js route handlers (server-side, session-guarded) |
| Database | Prisma ORM — SQLite in the dev runtime, PostgreSQL (Supabase) in production |
| Auth | Email + password with scrypt hashing, httpOnly session cookies, role-based server-side guards |
| Hosting | Cloudflare Pages — https://jee-nexus-5wd.pages.dev |

### Repository layout

```
prisma/            Prisma schema (20 normalized models)
supabase/           PostgreSQL migrations + Row Level Security (production DB)
src/app/            Next.js app routes
src/app/api/        Server-side API route handlers
src/lib/            Domain types, auth, services, exam marking engine
src/components/     UI components (shadcn/ui + custom)
data/questions/     Question seed data (JSON, verified)
landing/            Static public landing page (deployed to Cloudflare Pages)
scripts/            Operational scripts (account checks, deployment, seeding)
```

## Data integrity policy

- Questions carry a `verificationStatus`: `imported → needs_review → verified / rejected`. Nothing shows as *verified* unless it actually is.
- Duplicate detection via normalized `contentHash` on every question.
- Solutions generated by AI are labelled *AI-generated* until an expert verifies them.
- Development seed data is labelled as such and never presented as production data.

## Local development

```bash
bun install
cp .env.example .env        # fill in values
bun run db:push             # sync Prisma schema
bun run dev                 # start dev server on :3000
```
